# number-systems-and-binary-codes
Python program for decimal-to-binary conversion and operations with direct, inverse, and two's complement binary codes.

The project was developed as part of university work during my second year of study.

## Key Variables
* a - positive decimal number;
* b - negative decimal number;
* bina - binary representation of the positive number;
* binb - binary representation of the absolute value of the negative number;
* resa - 7-bit binary representation of the positive number;
* resb - 7-bit binary representation of the absolute value of the negative number;
* sum1 - result of subtraction in direct code;
* sum_bin - binary representation of the subtraction result;
* res_sum1 - formatted result of the operation in direct code;
* invb - binary representation used to obtain the inverse code;
* reverse - inverse binary code of the negative number;
* res_rever - 7-bit inverse code;
* sum2 - result of addition in inverse code;
* sum_bin2 - binary representation of the addition result in inverse code;
* res_sum2 - formatted result in inverse code;
* res_dop - additional (two's complement) code of the negative number;
* sum3 - result of addition in additional code;
* sum_bin3 - binary representation of the addition result in additional code;
* res_sum3 - formatted result in additional code.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/dolzhkris/number-systems-and-binary-codes.git
```

2. Run the program:

```bash
python main.py
```
